# 论文写作规范
1. 引入的创新点一定要有动机，一定是为了解决某个通用问题而不是限定针对某个具体数据集，比如我们论文里主要针对一个小麦数据集进行实验，你要解决的应该是小麦自身的问题，而不是这个数据集特定的问题。
2. 你的每个创新点肯定不是凭空产生的，肯定收到一些工作的启发，进行了发展和改进，所以在方法里要引用这些工作。
3. 不要说什么冠军方案了，直接是SOTA，然后比赛的也要少提，主要关注小麦的问题。
4. 相关工作部分要按问题而不是技术来组织。
5. 一定要参考基线方法论文和数据论文，有些数据直接使用就好，比如一些实验数据。

# LaTex 规范
1. 写作一定要规范，咱们是写论文，不是技术报告，减少使用各种分条、加粗、破折号、引号等不规范样式。
2. 引用论文使用`citep`，引用图片表格等，使用`cref`。
3. 引用一定要真实，bib中要带doi号或url网址。
4. 对于占位图片，要使用类似\fbox{}，先画出个框来，同时将 \includegraphics[width=\linewidth]{figures/}也写上，但是先注释掉，占位图上应该写上这个图的内容应该是什么，好指导我放图。它的模板如下：：
```
\begin{figure*}[!t]
\centering
%\includegraphics[width=0.95\linewidth]{XXX.pdf}
\fbox{\parbox{0.95\linewidth}{\centering \vspace{1.5cm} 占位符：XXX }}}
\caption{XXX}
\label{fig:XXX}
\end{figure*}
```
5. 对于一些可能会更换的名称，如何创新的模块名，尽量使用宏，如`\newcommand{\OURS}{MSO-Det\xspace}`,在用宏时一定要注意，和后边的中文之间空一个格，不然会有语法错误。
6. 使用中文。  
7. 对于【占位符】，用蓝色标记出来，定义成一个宏。
