# TopoWheat 实验补充清单

本文档用于把实验输出映射到 `Manuscript.tex` 及 `content/experiments.tex` 中的蓝色占位符。正式填数前应冻结数据划分、代码版本和随机种子，避免不同表格引用不一致的实验。

## 1. 先冻结实验协议

- [ ] 确认少标注协议为 99 张有标注训练图、64,368 张无标注训练图、99 张验证图和 110 张未知域测试图。
- [ ] 确认完整数据地域划分的训练域、验证域和测试域，并记录各域实际样本数。
- [ ] 确定完整数据的低标注比例，建议使用 10%、25%、50% 和 100%。
- [ ] 固定 3 或 5 个随机种子；主结果报告均值和标准差。
- [ ] 固定骨架化方法、边界容差、延迟预热次数、GPU 型号和批大小。
- [ ] 建立统一实验记录，至少保存配置、Git 提交、日志、预测掩码和逐图指标。

## 2. 最小主实验矩阵

| 编号 | 训练配置 | 推理配置 | 主要用途 |
|---|---|---|---|
| E0 | 监督基线 | 单尺度 | 统一主干基准 |
| E1 | E0 + TRPL | 单尺度 | 验证创新点一 |
| E2 | E1 + TCPM | 单尺度 | 验证创新点二 |
| E3 | E2 | BAZR，默认 K | 完整方法与创新点三 |
| E4 | E2 | 密集多尺度滑窗 | 精度上限和效率比较 |
| E5 | 已发表方案复现 | 论文原推理 | 公平复现基线 |

E0--E4 必须使用同一数据划分、主干网络和训练预算。E2 与 E3 应共享模型权重，从而将 BAZR 的收益与训练改动分离。

## 3. TRPL 专项实验

- [ ] 固定类别阈值。
- [ ] 仅使用预测熵。
- [ ] 使用熵与多视图一致性。
- [ ] 完整中心线--区域解耦。
- [ ] 去掉不确定边界忽略掩码。
- [ ] 去掉 clDice 或骨架一致性项。
- [ ] 统计茎秆伪标签接纳率、中心线准确率、断裂数、Stem IoU 和 clDice。
- [ ] 在隐藏验证标签上离线评估伪标签，不把该标签用于训练或模型选择。

## 4. TCPM 专项实验

- [ ] 无原型：`configs/gwfss/experiments/competition_topowheat_trpl.yaml`。
- [ ] 完整高置信区域：`configs/gwfss/experiments/ablations/tcpm_reliable_core.yaml`。
- [ ] 形态学收缩内部区域：`configs/gwfss/experiments/ablations/tcpm_eroded_core.yaml`。
- [ ] 拓扑核心但立即启用损失与伪标注记忆：`configs/gwfss/experiments/ablations/tcpm_immediate.yaml`。
- [ ] 课程启用但只维护有标注记忆：`configs/gwfss/experiments/ablations/tcpm_labeled_memory.yaml`。
- [ ] 双记忆但不使用逐样本留一域：`configs/gwfss/experiments/ablations/tcpm_no_lodo.yaml`。
- [ ] 完整 TCPM：`configs/gwfss/experiments/competition_topowheat_trpl_tcpm.yaml`。
- [ ] 统计验证 mIoU、最差源域 mIoU、未知域测试 mIoU、域间原型距离及 TensorBoard 中的 `tcpm/labeled_drift` 和 `tcpm/pseudo_drift`。
- [ ] 输出按域着色、按类别和标注来源标记的 UMAP 图；所有设置使用相同的抽样、随机种子、拟合参数和坐标范围。

## 5. BAZR 专项实验

- [ ] 单尺度全局推理，K=0。
- [ ] 仅熵路由。
- [ ] 熵加茎秆概率。
- [ ] 完整断裂感知路由。
- [ ] K=2、4、8 的预算曲线。
- [ ] 密集多尺度滑窗。
- [ ] 统计 mIoU、Stem IoU、异常端点覆盖率、前向次数、FLOPs、延迟和峰值显存。
- [ ] 延迟包含窗口评分、裁剪和融合，并至少预热 20 次、测量 100 次。

## 6. 主表与统计要求

- [ ] 少标注协议主表填入验证 mIoU、测试 mIoU、Stem IoU、clDice 和前向次数。
- [ ] 完整数据地域表填入四类 IoU 和 mIoU。
- [ ] 所有自有方法结果填写均值和标准差。
- [ ] 对核心对比执行逐图配对显著性检验，并报告 95% 置信区间。
- [ ] 按地面采样距离、生育阶段和茎秆像素占比分组分析。
- [ ] 检查摘要、结论、正文和表格中的同一数值完全一致。
- [ ] 完成结果后再统一标注最佳和次优值，不提前加粗占位结果。
